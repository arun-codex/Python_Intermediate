PART 3 — FUNCTION REVISION
--------------------------

Spend about 20 minutes.

Basic function:

def greet():
    print("Hello")

greet()

Function with parameter:

def greet(name):
    print("Hello", name)

greet("Arun")

Function with return:

def add(a, b):
    return a + b

result = add(10, 20)
print(result)

IMPORTANT:
A parameter is information given to a function.
return sends a result back to the code that called the function.

INTERMEDIATE MINDSET
--------------------

Instead of writing everything in one block:

marks = [80, 90, 70]

total = sum(marks)
average = total / len(marks)

Use reusable functions:

def calculate_total(marks):
    return sum(marks)

def calculate_average(marks):
    return sum(marks) / len(marks)

The goal is to start breaking large problems into smaller reusable functions.
